# Bloom & Brew Cafe Website

A responsive cafe website built with HTML, CSS, and JavaScript. 

Features include dark mode, smooth navigation, interactive UI elements, and a modern aesthetic design.

This project was created to showcase front-end web development skills including responsive layouts, interactive navigation, dark mode functionality, and modern UI design.

---

## 🚀 Features

- Responsive design for desktop and mobile devices
- Interactive navigation menu
- Dark mode / light mode toggle
- Smooth scrolling between sections
- Modern café-themed user interface
- Organized and maintainable code structure
